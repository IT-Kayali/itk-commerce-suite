# Packages

The Commerce Suite is delivered as independently versioned WordPress packages.

| Package | Type | Initial status | Responsibility |
| --- | --- | --- | --- |
| `itk-commerce-theme` | Theme | Foundation | Design system, patterns, layouts and responsive UI |
| `itk-commerce-core` | Plugin | Foundation | Settings, modules, import/export, updates and roles |
| `itk-commerce-multilingual` | Module | Planned | Languages, translations, RTL/LTR, hreflang and email language |
| `itk-commerce-elementor` | Module | Planned | Theme locations, widgets, dynamic data and templates |
| `itk-commerce-layouts` | Module | Planned | Shop, product, cart, checkout and account layout models |
| `itk-commerce-search-filter` | Module | Planned | AJAX search, SKU search, filter builder and off-canvas filters |
| `itk-commerce-documents` | Module | Planned | Invoice, delivery note, return and packing list |
| `itk-commerce-badges` | Module | Planned | Sale, percentage, sold-out, new and custom badges |
| `itk-commerce-wishlist-compare` | Module | Planned | Wishlist and product comparison |
| `itk-commerce-gift-boxes` | Module | Planned | Configurable gift boxes and mixtures |
| `itk-commerce-code-manager` | Module | Planned | Controlled HTML/CSS/JS/PHP extension points |

A planned package directory is created only when implementation begins so the repository does not accumulate empty placeholders.
