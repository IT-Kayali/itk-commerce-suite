# Al-Lord Reference Profile

This directory is reserved for the first reference implementation of the IT-Kayali Commerce Suite.

Rules:

- Al-Lord-specific branding and configuration belong here, not in the generic theme/core/modules.
- Production customer/order data must not be committed.
- Secrets and credentials must not be committed.
- Configuration will be versioned and exportable once the profile schema is implemented.
- Deployment must preserve the current WooCommerce production data during the final migration and cutover process.
